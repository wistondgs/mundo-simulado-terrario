# PRIMITIVO · Entidad Transitoria

Estado de rama: `ETP-PRE-00 · FUNDACIÓN Y DISECCIÓN CAUSAL PREEXPERIMENTAL`.

PRE-01 está cerrado como atlas basal verificado; no habilita todavía una
intervención.

Esta área estudia, sin presuponer una entidad, el fenómeno
`perturbación → organización transitoria → reconstrucción → desaparición`.
El nombre neutral es **organización transitoria candidata**. «Entidad
transitoria primitiva» sólo se usará si la evidencia lo permite y
«proto-orgánulo» queda reservado para H3.

No se construye un agente, no se modifica Terrario/Genesis/RNFE/APD, ni se
ejecutan experimentos. A es el objeto primario congelado; B queda como
contraste proyectado no compilable.
