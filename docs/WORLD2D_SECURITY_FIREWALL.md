# Scientific firewall

All live records are `ENGINEERING_SANDBOX`, `scientific_evidence=false`. `EvidenceFirewall` rejects them and no WorldStream module imports an EvidenceGraph writer. There is no scientific execution endpoint or button.

Observer verbosity cannot widen the agent projection. Camera, overlays, visibility controls, and timeline filters never enter agent input. World Truth and forensic provenance remain separately labelled privileged/observer-only data.

Protected ReferenceGraph, TheoryGraph, EvidenceGraph, locked preregistrations, A0–A4, and H-ADAPT artifacts are outside this change. H-ADAPT is not executed.
