# Timeline and forensics

The event timeline virtualizes visible rows and retains authoritative action/runtime events independent of render cadence. Scrub and keyboard navigation select recorded frames without rewinding the live runtime.

Frame comparisons report added, removed, moved, and property changes. They are always marked `DERIVED STATE DIFF · NOT CAUSAL`. World-object selection follows stable `object_id`; Agent View offers no identity unless the explicitly labelled observer forensic sidecar provides a mapping.

D2 use is limited to visibility/provenance inspection. The UI does not infer concepts, cognitive binding, or scientific evidence. PNG export is watermarked `DIAGNOSTIC VIEW · NOT SCIENTIFIC EVIDENCE`.
