# Experiment Portfolio

The current snapshot supplies one entry for every `HYPERCAND-01` through `HYPERCAND-08`. The API and Lab UI expose rivals, predictions, interventions, controls, confounders, identifiability, cost, priority, warnings, provenance, and blockers. Entries can be searched and filtered by `CPU_READY`, `GPU_REQUIRED`, or `NEW_ENVIRONMENT_REQUIRED`; readiness is capability triage, not approval.

Special review rules:

- HYPERCAND-01 flags factorial explosion and requires comparison of screening, fractional, sequential, and adaptive strategies before a full factorial.
- HYPERCAND-03 separates retention and transfer as possible mechanisms versus outcomes and flags construct circularity.
- HYPERCAND-04 treats stage order as historically descriptive, never automatically causal or necessary.
- Collective candidates warn that aggregate performance alone is not collective intelligence; interaction topology, communication, coordination, memory, emergence, group transfer, and adversarial robustness need explicit operationalization.

All entries retain `HUMAN_REVIEW_REQUIRED`. Current automatically detected capability gaps and every unmitigated critical confounder remain visible blockers. No H-ADAPT run is initiated by portfolio construction or display.
