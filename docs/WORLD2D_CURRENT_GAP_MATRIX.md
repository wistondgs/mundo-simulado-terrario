# World2D current → gap → target matrix

Audit performed on `f0e5540` before the temporal-forensics continuation. This matrix describes the implementation; it does not turn engineering-sandbox observations into scientific evidence.

| Current | Gap observed | Target | Invariant | Performance risk |
|---|---|---|---|---|
| Live runtime emits atomic `WorldFrame`s with all three epistemic views. | None in frame identity; viewer must reject mismatched ticks. | Keep same-tick status explicit. | `WorldTruth_t != AgentObservation_t != ObserverView_t`; no view is silently relabelled synchronized. | Serializing large privileged frames can exceed the frame budget. |
| Agent frame is built from `world.get_observation`; Observer provenance is a sidecar. | None found that derives Agent View from World Truth in the viewer. | Preserve direct ObservationContract payload. | Viewer settings never alter the observation payload. | Observation channel grids dominate payload size at high resolution. |
| JSONL trace has sequence/hash chain and SQLite index. | Generic `seek` could land on a later STATUS/EVENT at the same tick. | Frame-specific indexed seek and arbitrary frame comparison. | JSONL remains authoritative; index/checkpoints remain rebuildable. | Per-record fsync favors crash consistency over high append throughput. |
| Client had bounded ingress but an unbounded `Map` of rendered frames. | A long live session could grow browser memory without bound. | Bounded presentation history plus indexed server fetch for old ticks. | Dropping presentation frames never drops trace events or logical transitions. | Old-tick navigation adds one indexed request. |
| Timeline had adjacent diff and stable selection. | No arbitrary comparison, local bookmark, or retained entity history. | Derived comparison, local-only bookmark, World Truth identity history, typed lanes. | State diffs are labelled non-causal; bookmarks are not evidence. | Entity history is limited to the presentation window unless a trace range is loaded. |
| Canvas is the measured primary renderer; WebGL2 is a fallback-capable implementation. | WebGL allocated a typed array per frame and both backends scanned objects for picking. | Capacity-reused GPU buffer and O(1) presentation pick index. | Renderer failure stays local to its view and cannot affect the runtime. | Three-view 10k/50k browser benchmarks remain required before renderer promotion. |
| Restart discovery, subscriber caps, gap/resync, and `SESSION_LOST` exist in the service. | Browser restart/reconnect flow still needs a fully executable local browser matrix. | Exercise it in Chromium and Firefox when this environment exposes a native Node/browser runtime. | A lost session is never reconstructed from guesses; valid trace remains playback-only. | Slow clients can require snapshot resync after ring eviction. |
