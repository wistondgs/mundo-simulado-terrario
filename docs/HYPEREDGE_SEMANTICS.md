# Hyperedge Semantics

`HYPERCAND-01` through `HYPERCAND-08` are imported as
`TESTABLE_CONJUNCTION`. Components, outcome, base, attribution, conjunction
explicitness, necessity, sufficiency, level, discriminating test, confounders
and decision are preserved verbatim.

The graph represents components jointly through a single hyperedge candidate
node. It never emits `ESTABLISHED_CAUSAL_HYPEREDGE`. High relation strength is
metadata about the claim and is not equivalent to truth or causality.
