# Causal Fork Failure Model

Failures fail closed: `FORK_NOT_SUPPORTED`, `SNAPSHOT_INCOMPLETE`,
`SNAPSHOT_CORRUPT`, `SCHEMA_MISMATCH`, `SOFTWARE_INCOMPATIBLE`,
`RESTORE_NOT_EXACT`, `BRANCH_ALIASING_DETECTED`, `INTERVENTION_INVALID`, and
`INTERVENTION_UNSUPPORTED`. No partial restore or implicit defaults are allowed.
