# World2D renderer

The native interface is `initialize`, `resize`, `setCamera`, `renderFrame`, `pick`, `dispose`, and `metrics`. Canvas2D is the permanent fallback and renders exact agent channel zero plus mask rather than pretending the observation contains world objects. WebGL2 uses capacity-grown reusable GPU buffers (`bufferSubData` per frame, rather than a new typed array and allocation per paint) and point rendering for world entities. Both renderers maintain a presentation-only coordinate index for O(1) picking rather than scanning every visible object.

Context loss or local renderer failure replaces only the affected renderer with Canvas2D. rAF presents the newest logical frame; authoritative events remain in the reducer/timeline. Canvas is currently primary: no reproducible three-view 10k benchmark has yet demonstrated the required ≥20% WebGL2 p95 win with visual/picking parity. WebGL2 remains available behind the renderer abstraction, not asserted as the primary path without that evidence.
