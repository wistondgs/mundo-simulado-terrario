# Scientific runtime contract

`ScientificTrialIdentity` binds execution, intent, attempt, plan, preregistration root, software, scenario, agent and both explicit seeds. `ScientificFrame` carries that identity plus an atomic three-view frame contract. Frames are observational: no scientific UI command changes simulation time or the sealed plan. A missing post-step agent observation is represented as `NOT_RETAINED_IN_RAW_STEP_TRACE`, never fabricated from truth.
