# Evidence Graph

The evidence layer links project hypothesis, experiment metadata, runs, raw
evidence references and recorded metrics. It indexes paths and does not copy or
rewrite raw evidence.

H-ADAPT-001 is `UNTESTED_HYPOTHESIS` and
`PROJECT_HYPOTHESIS_WITHOUT_COMPLETE_THEORY_LINKAGE`. Pilot artifacts are
historical records, not confirmatory evidence. No `EVIDENCE_FOR` or
`EVIDENCE_AGAINST` edge is created without an explicit scientific decision.
